# Descargador de Videos de YouTube

Un mini proyecto hecho en **Python** para descargar videos de YouTube de forma sencilla, rápida y sin complicaciones.

La idea del proyecto es ofrecer una herramienta con una **interfaz amigable para el usuario**, fácil de usar y pensada para que cualquier persona pueda descargar videos sin tener que usar comandos complicados.

## Características

* Descarga videos de YouTube fácilmente.
* Interfaz simple y amigable.
* Proyecto libre de virus.
* Código abierto y disponible para revisión.
* Fácil de instalar y ejecutar.
* Pensado como proyecto educativo y práctico en Python.

## Tecnologías utilizadas

* Python
* yt-dlp
* CustomTkinter

## Instalación

Primero clona este repositorio:

```bash
git clone https://github.com/TU-USUARIO/TU-REPOSITORIO.git
```

Entra a la carpeta del proyecto:

```bash
cd TU-REPOSITORIO
```

Crea un entorno virtual:

```bash
python -m venv venv
```

Activa el entorno virtual.

En Windows:

```bash
venv\Scripts\activate
```

En Linux o macOS:

```bash
source venv/bin/activate
```

Instala las dependencias:

```bash
pip install -r requirements.txt
```

## Uso

Ejecuta el archivo principal:

```bash
python main.py
```

Después solo pega el enlace del video de YouTube, selecciona las opciones disponibles y descarga el video.
